# User Guide

## Admin

Admins can view dashboards, manage projects, manage test cases and suites, execute tests, and access user management APIs.

## Test Lead

Test leads can create and modify projects, test cases, and suites. They can assign and execute tests and view all reports.

## Tester

Testers can view projects, suites, and test cases. They can execute tests and update execution results.

## Read Only

Read-only users can view dashboards, projects, suites, test cases, and execution history. Write and execution actions are hidden or disabled.
